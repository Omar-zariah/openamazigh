# Contributors

Thank you to everyone who has contributed to OpenAmazigh!

## How to Contribute

We welcome contributions in many forms:

### Content Contributions
- **Dictionary Entries**: Add new words, improve translations
- **Lessons**: Create or improve learning content
- **Audio**: Record pronunciations for words
- **Cultural Content**: Share stories, traditions, history

### Code Contributions
- **Features**: Add new functionality
- **Bug Fixes**: Fix issues and improve stability
- **API**: Extend API endpoints
- **Documentation**: Improve docs and guides

### Other Contributions
- **Testing**: Test features and report bugs
- **Design**: Improve UI/UX
- **Translation**: Translate the platform
- **Feedback**: Share ideas and suggestions

## Contribution Process

1. Visit `/contribute` page
2. Fill out the contribution form
3. Submit your contribution
4. We'll review and integrate it

## Code Contributions

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a Pull Request

See [CONTRIBUTING_GUIDE.md](../CONTRIBUTING_GUIDE.md) for details.

## Recognition

All contributors will be:
- Listed here
- Credited in releases
- Acknowledged in the project
