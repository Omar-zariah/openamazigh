# OpenAmazigh Features

A comprehensive list of all features available in the OpenAmazigh platform.

## 🎓 Learning Tools

### Dictionary
- **Searchable Dictionary**: 25+ entries with Tifinagh script
- **Advanced Search**: Search by word, translation, or pronunciation
- **Category Filtering**: Filter by categories (Greetings, Family, Numbers, etc.)
- **Favorites System**: Save favorite words for quick access
- **Pronunciation Guide**: Phonetic transcriptions for each word
- **Example Sentences**: Contextual examples for each entry

### Lessons
- **6 Complete Lessons**: Structured learning path from beginner to advanced
- **Interactive Content**: Rich text with Tifinagh script examples
- **Practice Exercises**: Exercises included with each lesson
- **Progress Tracking**: Automatic saving of completed lessons
- **Navigation**: Previous/Next lesson navigation
- **Completion Status**: Visual indicators for completed lessons

### Quiz System
- **10 Questions**: Comprehensive quiz covering language and culture
- **Real-time Feedback**: Immediate feedback on answers
- **Score Tracking**: Track your quiz scores over time
- **Explanations**: Detailed explanations for each answer
- **Progress Visualization**: Visual progress bars and percentage scores

### Flashcards
- **Interactive Flashcards**: Click to flip and learn
- **13+ Vocabulary Cards**: Common words and phrases
- **Shuffle Function**: Randomize card order
- **Study Tracking**: Mark cards as studied
- **Progress Indicators**: Track your study progress

### Typing Practice
- **Tifinagh Typing**: Practice typing Tifinagh characters
- **Real-time Feedback**: Instant feedback on accuracy
- **Speed Tracking**: Words per minute (WPM) calculation
- **Accuracy Metrics**: Track your typing accuracy
- **Pause/Resume**: Control your practice sessions

### Alphabet Learning
- **Complete Alphabet**: All 25+ Tifinagh letters
- **Interactive Cards**: Click to see letter details
- **Pronunciation Guides**: Learn how to pronounce each letter
- **Example Words**: See letters in context
- **Search Functionality**: Quickly find specific letters

### Pronunciation Guide
- **8+ Words**: Common words with pronunciation
- **Phonetic Transcriptions**: Clear pronunciation guides
- **Audio Buttons**: Ready for audio integration
- **Example Sentences**: Words in context
- **Pronunciation Tips**: Helpful tips and rules

### Language Comparison
- **Side-by-Side Comparison**: English vs Tamazight vs Tifinagh
- **Category Filtering**: Filter by word categories
- **Pronunciation Guides**: Learn correct pronunciation
- **Interactive Table**: Easy to read comparison format
